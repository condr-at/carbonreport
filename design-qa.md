- **Цвет:** синий `#315ee6`, белые/ледяные поверхности; dark `#0c1628`, карточки `#132139`, акцент `#91b1ff`. Общие CSS tokens применены и к приложению. Проверенные пары контраста: light CTA 5.42:1, light body 5.23:1, dark CTA 7.18:1, dark body 8.87:1. Есть видимый focus и reduced-motion правило.
- **Изображения:** пять WebP из реального локального продукта/проверенного ZIP, синтетические данные, без частных email/sidebar. Вместо воображаемого GHG-документа показан текущий supplier export. HTML-пример побайтово совпадает с экспортом. Lucide — единая семья иконок; нарисованные заглушки продукта не используются.
- **Тексты:** описан один текущий результат — CBAM supplier review package. Указаны входные specific-emissions значения, отдельные direct/indirect totals, HTML/JSON/CSV и ссылки на источники.
