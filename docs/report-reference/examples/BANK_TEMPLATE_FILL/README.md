# Образцы: BANK_TEMPLATE_FILL

Дата проверки: 2026-10-11. Статус материала: **official_reporting_tables_conditional**.

CE04 содержит sample tables, CE05 — более ранний checklist. Настоящая анкета конкретного банка остаётся обязательным входом.

## Доступные ориентиры

- **CE04** [Financed Emissions, Part A, Third Edition](https://carbonaccountingfinancials.com/files/standard-launch-2025/PCAF-PartA-2025-V3-December.pdf) — PCAF; December 2025; доступ: public. [Локальный материал](../../assets/client-energy/pcaf-part-a-third-edition-2025.pdf). Contains reporting examples in section 10.2. For financial institutions; not every borrower questionnaire is PCAF. Verified sample-table section starts on PDF page 199 in downloaded copy; TOC page references differ.
- **CE05** [Disclosure Checklist, Part A Financed Emissions](https://carbonaccountingfinancials.com/files/disclosure_checklist/PCAF-Disclosure-Checklist-Part-A-Financed-Emissions-May-2025.pdf) — PCAF; May 2025; доступ: public. [Локальный материал](../../assets/client-energy/pcaf-disclosure-checklist-may-2025.pdf). Predates third edition December 2025; compare against CE04 before use.

## Как использовать

- Сначала сопоставить страну, период, редакцию, объект и границы с нашим кейсом.
- Официальная форма задаёт структуру только для своей схемы и версии. Публичный заполненный отчёт показывает один конкретный случай.
- Не переносить чужие цифры, подписи, логотипы проверки и утверждения о сертификации в наш результат.
- Для проверки расчёта нужны исходные данные, коэффициенты и ожидаемый результат; одного красивого PDF недостаточно.
- Статус golden test: **не утверждён**. Отдельно согласовать контракт и критерии численной/содержательной приёмки.
