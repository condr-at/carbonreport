# Образцы: EU_ETS

Дата проверки: 2026-10-11. Статус материала: **official_forms_and_verifier_example**.

Локальные актуальные XLSX для stationary и aviation; отдельный заполненный verification exemplar. Последний не универсальный AER и не подпись по клиенту.

Национальный authority может использовать свою версию/ERT.
- **TR31** [EU ETS/Swiss ETS/CORSIA Template 5: aircraft AER](https://climate.ec.europa.eu/document/download/4a327569-5092-4d55-a457-530a5a4eb487_en?filename=t5_aer_aircraft_en.xlsx) — European Commission, DG CLIMA; 2026-01-23; доступ: public_downloaded. [Локальный материал](../../assets/trade-transport/ets-corsia-aircraft-aer-20260123.xlsx). 17 sheets, включая CORSIA emissions/fuels; разделять границы режимов. Это EU reporting context, не универсальный ICAO filing format.
- **TR32** [EU ETS exemplar verification report: installation](https://climate.ec.europa.eu/document/download/84c3bff8-0ba4-4657-a594-c8430597f115_en?filename=examplar_avr_verification_installations_en.pdf) — European Commission, DG CLIMA; дата файла отдельно не подтверждена; index checked 2026-10-11; доступ: public_downloaded. [Локальный материал](../../assets/trade-transport/ets-installation-verification-exemplar.pdf). Учебный заполненный пример верификатора, не годовой emissions report и не реальное заключение по клиенту.

## Как использовать

- Сначала сопоставить страну, период, редакцию, объект и границы с нашим кейсом.
- Официальная форма задаёт структуру только для своей схемы и версии. Публичный заполненный отчёт показывает один конкретный случай.
- Не переносить чужие цифры, подписи, логотипы проверки и утверждения о сертификации в наш результат.
- Для проверки расчёта нужны исходные данные, коэффициенты и ожидаемый результат; одного красивого PDF недостаточно.
- Статус golden test: **не утверждён**. Отдельно согласовать контракт и критерии численной/содержательной приёмки.
