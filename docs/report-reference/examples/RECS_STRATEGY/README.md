# Образцы: RECS_STRATEGY

Дата проверки: 2026-10-11. Статус материала: **guidance_only_no_universal_form**.

Сохранён официальный procurement guide; единого нормативного отчёта RECs Strategy нет.

## Доступные ориентиры

- **CE08** [Guide to Purchasing Green Power, chapter 6: Contracting](https://www.epa.gov/sites/default/files/2018-08/documents/guide-purchasing-green-power-6.pdf) — EPA / DOE / WRI / CRS / NREL; 2018; linked by EPA page updated 2026-09-21; доступ: public. [Локальный материал](../../assets/client-energy/epa-green-power-contracting-2018.pdf). Procurement reference and contract considerations; not a signed contract or official strategy form.

## Как использовать

- Сначала сопоставить страну, период, редакцию, объект и границы с нашим кейсом.
- Официальная форма задаёт структуру только для своей схемы и версии. Публичный заполненный отчёт показывает один конкретный случай.
- Не переносить чужие цифры, подписи, логотипы проверки и утверждения о сертификации в наш результат.
- Для проверки расчёта нужны исходные данные, коэффициенты и ожидаемый результат; одного красивого PDF недостаточно.
- Статус golden test: **не утверждён**. Отдельно согласовать контракт и критерии численной/содержательной приёмки.
