# Образцы: ENERGY_AUDIT_SCOPE12

Дата проверки: 2026-10-11. Статус материала: **official_checklist_and_templates**.

Сохранены phase-4 A3 и B, официальный A1/A2 доступен по ссылке; это UK-примеры, не универсальный EU-аудит.

- **CE11** [ESOS phase 4 report checklists A1/A2](https://www.gov.uk/government/publications/comply-with-the-energy-savings-opportunity-scheme-esos-phase-4/appendices-a1-and-a2-report-checklists-for-participants) — UK Environment Agency; Published 2026-07-30; доступ: public.

[Локальный материал](../../assets/client-energy/esos-phase4-recommendations-template.odt). Suggested presentation of recommendations, not the entire mandatory report.
- **CE13** [ESOS phase 4 notification fields, Appendix B](https://assets.publishing.service.gov.uk/media/6a69f658701b2d693e5b9422/ESOS_Appendix_B_phase_4.odt) — UK Environment Agency; Phase 4; landing page 2026-07-30; доступ: public. [Локальный материал](../../assets/client-energy/esos-phase4-notification-fields.odt). Fields for MESOS notification; portal submission is separate from report generation.

## Как использовать

- Сначала сопоставить страну, период, редакцию, объект и границы с нашим кейсом.
- Официальная форма задаёт структуру только для своей схемы и версии. Публичный заполненный отчёт показывает один конкретный случай.
- Не переносить чужие цифры, подписи, логотипы проверки и утверждения о сертификации в наш результат.
- Для проверки расчёта нужны исходные данные, коэффициенты и ожидаемый результат; одного красивого PDF недостаточно.
- Статус golden test: **не утверждён**. Отдельно согласовать контракт и критерии численной/содержательной приёмки.
