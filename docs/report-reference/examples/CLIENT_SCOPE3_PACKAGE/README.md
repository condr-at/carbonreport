# Образцы: CLIENT_SCOPE3_PACKAGE

Дата проверки: 2026-10-11. Статус материала: **official_schema_conditional**.

Официальные модель/схема PACT сохранены; не образец любого клиентского запроса.

## Доступные ориентиры

- **CE02** [PACT Simplified Data Model](https://docs.carbon-transparency.org/tr/data-exchange-protocol/latest/pact-simplified.xlsx) — WBCSD PACT; 3.0.3 snapshot 2026-10-11; доступ: public. [Локальный материал](../../assets/client-energy/pact-v3.0.3-data-model.xlsx). Dictionary/workbook, not a filled client report; latest URL is mutable.
- **CE03** [PACT OpenAPI including examples](https://docs.carbon-transparency.org/tr/data-exchange-protocol/latest/openapi.yaml) — WBCSD PACT; 3.0.3 (verified info.version); доступ: public. [Локальный материал](../../assets/client-energy/pact-v3.0.3-openapi.yaml). Source schemas and example values for an agreed PACT exchange. Does not implement PCF calculation.

## Как использовать

- Сначала сопоставить страну, период, редакцию, объект и границы с нашим кейсом.
- Официальная форма задаёт структуру только для своей схемы и версии. Публичный заполненный отчёт показывает один конкретный случай.
- Не переносить чужие цифры, подписи, логотипы проверки и утверждения о сертификации в наш результат.
- Для проверки расчёта нужны исходные данные, коэффициенты и ожидаемый результат; одного красивого PDF недостаточно.
- Статус golden test: **не утверждён**. Отдельно согласовать контракт и критерии численной/содержательной приёмки.
