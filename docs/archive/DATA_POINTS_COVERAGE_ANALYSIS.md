## Дополнительные замечания

### Условные data points

Некоторые DP применимы только при определённых условиях:
- CBAM DP - только для импортёров определённых товаров
- Aviation/Maritime DP - только для соответствующих секторов
- SFDR/Banks DP - только для финансовых организаций

### Взаимосвязи

Многие новые DP связаны с существующими:
- `csrd_value_chain_mapping` → расширяет `value_chain_description`
- `product_system_boundary_description` → детализирует границы для PCF
- `sfdr_article_classification` → определяет применимость других SFDR полей
