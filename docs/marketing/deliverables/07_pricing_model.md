## 1. Ключевое решение: Dimension = Активные проекты

### Почему проекты, а не seats/отчёты/SKU

| Dimension | Вердикт | Причина |
|-----------|---------|---------|
| Per seat | ❌ | Не отражает ценность. Maria с 1 seat делает 50 отчётов |
| Per report | ❌ | Наказывает за активность, убивает value prop |
| Per SKU | ⚠️ | Близко, но не учитывает corporate reports |
| **Per project** | ✅ | Универсально: product И corporate = проект |

### Что такое "проект"

| Это 1 проект | Это НЕ отдельный проект |
|--------------|------------------------|
| "Алюминиевый профиль 40x40" (product) | Другой формат отчёта (CBAM → ISO 14067) |
| "Corporate CDP Report 2025" (corporate) | Обновление данных через квартал |
| "Стальная труба DN50" (product) | Новая версия того же отчёта |

### Что unlimited во всех планах

- ✅ Форматы экспорта (CBAM, ISO 14067, EPD, CDP, client-specific...)
- ✅ Версии/обновления отчёта
- ✅ Запросы поставщикам (email по клику)
- ✅ Количество поставщиков (suppliers ≠ users)

### Что лимитировано

- 🔢 **Активные проекты** — основной dimension тарификации
- 🔢 **Пользователи (seats)** — included в план + докупка

> **Важно:** Поставщики НЕ считаются как users. Они получают запросы и загружают данные, но не имеют доступа к функционалу платформы.

## 3. Текущая рабочая гипотеза (Beta Pricing)

```
┌─────────────────────────────────────────────────────────────┐
│  FREE (Beta Only)     │  STARTER              │  (Future)  │
│  €0                   │  €99/mo               │            │
│                       │                       │            │
│  1 активный проект    │  3 активных проекта   │  ...       │
│  1 user               │  3 users included     │            │
│  Unlimited exports    │  +€19/mo per seat     │            │
│                       │                       │            │
│  ⚠️ Только для beta   │  Основной план        │            │
└─────────────────────────────────────────────────────────────┘
```

> **Suppliers ≠ Users.** Поставщики загружают данные через формы/email, но не имеют доступа к платформе и не считаются в лимит seats.

### Логика архивации

- **Активные проекты** = считаются в лимит
- **Архивированные** = НЕ считаются (пока)
- Можно архивировать → освободить слот → создать новый
- Архивированные доступны read-only

## 5. Feature Details

### AI Data Agent (Professional+)

**Что делает:**
1. Получает contact list от пользователя
2. Автоматически рассылает запросы на данные
3. Ведёт follow-up переписку (напоминания, уточнения)
4. Собирает полученные документы (PDF, Excel, email attachments)
5. Расшифровывает и извлекает данные из документов
6. Заполняет соответствующие поля в проекте
7. Помечает поля для review пользователем

**Value prop:** "Поставщики отвечают агенту, не вам. Вы получаете заполненные поля."

**Источник боли:** `01_product_vision.md` — "Getting everyone's buy-in can be difficult", "Capturing reliable data across numerous suppliers"

### Verifier Collaboration (Professional+)

**Что делает:**
1. Пользователь приглашает верификатора/консультанта по email
2. Верификатор получает scoped доступ к проекту (read + comment)
3. Может оставлять комментарии к конкретным полям
4. Может аппрувить/реджектить заполненные поля
5. Audit trail всех комментариев и решений
6. Export комментариев для отчётности

**Value prop:** "Верификатор работает в той же системе. Нет пересылки файлов, всё в audit trail."

**Источник:** `04_messaging_positioning.md` — "Coming Soon: Invite your verifier to review"

## 6. Corporate Reports: Текущий подход

### Сейчас (Beta / v1)

- Corporate report (CDP, CSRD, TCFD) = **1 проект** наравне с product
- Нет отдельной тарификации
- Клиент сам решает, на что тратить слоты

### Потом (v2+)

- **Corporate Add-on:** Отдельный слот/тариф для corporate reports
- Почему: Corporate сложнее, требует больше данных, другой workflow
- Когда: После валидации спроса и понимания unit economics

```
┌─────────────────────────────────────────────────────────────┐
```

## 7. Что тестируем в Beta

| Гипотеза | Как проверяем |
|----------|---------------|
| €99/mo за 3 проекта — приемлемо для SME | Спрашиваем напрямую + fake door |
| "Проект" как dimension понятен | Наблюдаем confusion в онбординге |
| 3 проектов достаточно для старта | Сколько проектов создают beta users |
| Архивация — рабочий механизм | Используют ли, жалуются ли |
| AI Agent — killer feature или noise | Упоминают ли боль сбора данных, готовы ли платить за Professional |
| Verifier Collab — нужно или нет | Спрашиваем про текущий процесс с аудиторами |
| Corporate как обычный проект — ОК | Feedback от тех, кто делает corporate |

## 8. Messaging: Как объяснять

### Короткая версия

> "Платите за проекты и команду. Отчёты, форматы, поставщики — без лимитов."

### Сравнение с консультантом

> "Консультант: €500 за каждый отчёт. Три формата = €1,500.
> Carbon Report: €99/mo за 3 проекта × любое количество отчётов."

### Premium Features pitch

**AI Agent:**
> "Устали гоняться за поставщиками? AI-агент сам ведёт переписку, собирает документы и заполняет поля."

**Verifier Collaboration:**
> "Пригласите верификатора в проект. Он комментирует и аппрувит прямо в системе."

### FAQ

**Q: Что если мне нужен CBAM + ISO 14067 на один продукт?**
A: Это 1 проект. Форматы экспорта не лимитированы.

**Q: Что если я обновлю данные через квартал?**
A: Это тот же проект. Обновления включены.

**Q: Что с архивными проектами?**
A: Архивированные не считаются в лимит. Можно архивировать старые и создать новые.

**Q: А corporate отчёты (CDP, CSRD)?**
A: Сейчас = 1 проект как обычно. В будущем — отдельный Corporate Add-on с расширенным датасетом.

**Q: Поставщики считаются как users?**
A: Нет. Поставщики загружают данные через формы/email, но не имеют доступа к платформе. Unlimited поставщиков во всех планах.

**Q: Что если нужно больше пользователей?**
A: Докупайте seats по €19/mo за каждого. В плане уже включено N пользователей (зависит от тарифа).

**Q: Что такое AI Data Agent?**
A: Агент сам рассылает запросы поставщикам по вашему contact list, ведёт переписку, собирает документы и заполняет поля. Вы только проверяете результат.

**Q: Зачем приглашать верификатора?**
A: Он видит ваши данные, оставляет комментарии к полям и аппрувит — всё в одном месте, с audit trail.
