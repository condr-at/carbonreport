## Найденные и исправленные дефекты

| Дефект | Наблюдение / причина | Исправление |
| --- | --- | --- |
| Чужое имя проекта в SSR | Автоматический сценарий: API возвращал 403, но исходный HTML страницы содержал имя чужого проекта | Summary и dataset проверяют membership и организацию до чтения; недоступный проект даёт 404 |
| Преждевременная отправка анкеты | В production после предпоследнего «Далее» последний блок кратко появлялся и маршрут переходил к выбору отчётов | Отмена native default action у навигационных кнопок и разные keys у Next/Submit |
| Ложное «письмо отправлено» | Код игнорировал `Resend.error`, а register UI всегда показывал `sent`; исключение почты могло вернуть 500 после создания пользователя | Явный результат отправки; успешная регистрация сохраняет 201 и сессию при недоставленной почте, resend возвращает 503 |
| Неясное продолжение регистрации | При активной сессии страница предлагала только повторное письмо и возврат ко входу | Кнопка Continue to workspace и явный статус почты |
| Verification token в логах | Проверка исходников выявила логирование токена и claims | Удалены чувствительные логи; редиректы не переносят входные query-параметры |
