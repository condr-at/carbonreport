# Предложения после первого прохода новым пользователем

Основание — production браузерный проход 2026-10-11, без использования сценарной документации как инструкции пользователю. Дефекты вынесены в [отчёт](REPORT.md); ниже предложения, которые ещё не реализованы.

| Приоритет | Наблюдение | Предлагаемое изменение / проверка |
| --- | --- | --- |
| Высокий | После создания организации пользователь остаётся в настройках | Завершать первый запуск явным действием «Создать первый продукт»; проверять достижение первого отчёта без самостоятельного поиска Projects |
| Высокий | Пустой workspace встречает заголовком Join your organization и предупреждением о дублировании billing | Дать два равноправных понятных пути: создать свою организацию или войти по приглашению; объяснение дублирования показывать контекстно |
| Высокий | Для известного запроса CBAM общий опросник спрашивает размер компании, внутренние источники и бюджет | Добавить короткий вход «Клиент запросил CBAM-данные»: роль, продукт/установка, период, получатель; сохранить расширенный подбор для неопределившегося пользователя |
| Средний | Мастер переключается с английского на русский и обратно | Выбрать язык интерфейса и последовательно использовать его во всём маршруте, включая валидацию и термины |
| Средний | Overview показывает внутренний код CBAM_DATA_PACKAGE | Использовать пользовательское название отчёта; технический код оставить в экспорте или справочных сведениях |
| Средний | Пустой review показывает 23 однотипных ошибки, включая «unknown is not zero» для имён | Сгруппировать недостающее по шагам и показывать релевантные сообщения: имя обязательно, число неотрицательно, дата обязательна |
| Средний | Ссылки на доказательства заполняются после ручного ввода source ID | Предлагать выбор уже добавленного документа и создание ссылки рядом с выбросами; сохранить точные ID в машиночитаемом файле |

Положительные наблюдения: на Overview есть работающая следующая задача; пакет различает черновик и сохранённую версию; ошибки review ведут к полю; выгрузка объясняет состав ZIP и отдельно предупреждает, что документы не приложены. Не убирать эти подсказки при сокращении первого запуска.
